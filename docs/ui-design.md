# Attic UI 设计守则 —— "精美"的工程化拆解

> 供 Phase 3（UI v0）执行与验收。核心立场：**精美不是装饰，是纪律**。
> 廉价 UI 的根源几乎总是四件事：间距失序、字阶崩坏、颜色噪音、状态缺失——它们全部可检查、可自动化。

## 1. Design Token：唯一真相源

所有视觉数值进 token（CSS custom properties），组件**禁止**写死值：

| 维度 | 规则 |
|---|---|
| 间距 | 4px 基准刻度：4/8/12/16/24/32/48，禁止刻度外数值 |
| 字号 | 5 档封顶（12/13/15/18/24）；正文行高 1.5，标题 1.2 |
| 圆角 | 3 档（6/10/16），只按层级用，不混用 |
| 颜色 | 语义命名：`surface / raised / overlay / text-primary / text-secondary / text-muted / accent / ok / warn / danger`；深浅主题 = 换 token 值，组件零改动 |
| 阴影 | 3 档，仅表达高度 |

执行机制：stylelint 规则拦截裸 hex 与刻度外 px。**"精美"的第一半是对齐与间距纪律，这一节占一半分数。**

## 2. 层级：眼睛得知道先看哪

- 每屏**恰好一个**主操作：Play 是全屏唯一 accent 实心元素，其余一律描边/幽灵按钮。
- 60-30-10：中性底色占大头、次级色构建分区、accent ≤10% 面积。
- **眯眼测试**（squint test）：眯眼看界面，仍能分出三级层次才算过关。
- 信息密度即设计：版本列表是数据——数字一律 `font-variant-numeric: tabular-nums`；年代色码 chip（Classic/Indev/Infdev/Alpha/Beta/RC）；相对时间。双栏布局（收藏列表 | 详情页，Raycast/Prism 范式），搜索优先。

## 3. 排版与布局：抄公式与范式，不从 0 发明

排版是最不需要原创能力的部分——公式、组件、布局范式全是现成的。"从 0 开始难"的解法是站在三样东西上：

**三套公式**（间距/字号已在 §1 token 表落地，此处补字号之外的参数）：

| 参数 | 取值 | 说明 |
|---|---|---|
| 间距栅格 | 8pt（4 的倍数） | 样式表里不允许再出现 5/7/13 这类数值 |
| 行长 | 正文 45–75 字符（中文 35–45 字） | 超宽先断栏，不拉长行 |
| 栏宽 | 主内容区 max-width 1100–1280px | 行高沿用 token：正文 1.5、标题 1.2 |

**组件层直接套现成**：推荐 **Tailwind + shadcn-vue**——shadcn 不是"依赖一个组件库"，而是把组件源码复制进本仓库、外观全部由一组 CSS 变量驱动，与 §1 的 token 唯一真相天然同构：**改品牌 = 改 token 值，改布局 = 挪组件**。迭代语言从此从"这里感觉不对"变成"accent 挪到哪个元素、间距跳哪一档"——改动可枚举，评审可执行。备选 Naive UI / Element Plus（token 同样可覆写，品牌化天花板低一档）。落地注意：shadcn 新版默认 token 用 `oklch()` 色彩，老 WebKitGTK 未必全绿——按 §8 基线把变量值换成等效 sRGB hex。

**布局范式抄启动器同行，不抄后台模板**：Prism / HMCL / Steam / Battle.net 是同一个成熟骨架——左侧窄导航 + 中间主列表 + 右侧详情/操作区（与 §2 双栏范式一致）。admin dashboard 模板（表格 + CRUD）的信息架构与启动器完全不同，套上去必拆。

**Figma 参考（可选）**：Untitled UI 免费套件、GitHub Primer 设计文件——借的是**页面结构**（列表页怎么分组、设置页怎么分栏），不是照搬视觉。

**土办法自检**：截 3 个觉得好看的界面，用 devtools 量间距与字号——会发现间距全是 4/8 的倍数、字号全落在一条 ratio 曲线上。把量出的数字写进 token 表，"模板"就成型了。

## 4. 字体

- 一套西文 + 一套中文，全局例外为零：Inter/Geist + MiSans/HarmonyOS Sans/思源黑体。
- 版本 ID、路径、日志、数字：等宽（JetBrains Mono）。
- display 字体（含像素字体）**只允许出现在 hero/内容区**，chrome 区保持现代无衬线——见第 10 节"证据不是戏服"。
- 大写小标签 `letter-spacing: .06em`；正文 0。

## 5. 颜色：贵气来自底色，不来自 accent

- 深色主题为默认。底色**不用纯黑**：暖木炭（`#14120F` 系，偏棕——阁楼的灰与木），正文**不用纯白**：羊皮纸（`#E8E4DC` 系）。
- accent：**火把琥珀**（`#E8A33D` 系），全屏唯一高饱和；次级色苔藓绿。
- 层级抬升靠**明度步进**（surface→raised→overlay 各 +4% 亮度），阴影只做辅助；两个重阴影永远不叠。
- "贵气"两板斧：卡片顶部 1px 内高光 `box-shadow: inset 0 1px 0 rgba(255,255,255,.05)` + 1px 低对比描边。
- 对比度门槛：正文 WCAG AA（4.5:1）、大字 3:1，双主题都要过。
- **内容即装饰**（本项目独有的审美特权）：历史全景图、各时代真实图标、旧 splash 艺术——拿考古素材本身当视觉主角，比任何抽象装饰都有效，且零成本不撞风格。

## 6. 动效：200ms 律

- 微交互 120–200ms；进 ease-out、出 ease-in；**只动 `transform`/`opacity`**（GPU 友好，且是 WebKitGTK 基线内最安全的一档）。
- 骨架屏替代转圈；列表切换 fade-slide 8px；禁止整页大动效。
- Play 按下 `scale(0.97)` 回弹；启动成功一次性"火把点燃"微动画——**全应用唯一品牌时刻**，稀缺才有记忆点。
- 尊重 `prefers-reduced-motion`。
- 规则：同屏同时播放的动画超过两个，删一个。

## 7. 状态完备性："精美"到"专业"的分界线

- 每个交互元素五态齐全：default / hover / active / focus-visible / disabled；focus ring 用 2px accent。
- 空状态 = 插画 + 一句话 + **行动按钮**（无实例时直接给"安装 c2.0_02"）。
- 错误状态 = 原因 + 出处 + 出路（沿用 MCANextGen Java 探测面板范式：列出全部候选与每个失败原因，绝不只说"未找到"）。
- 加载必须有数字（MB/s、第 n/m 项）——下载是启动器主场景。
- 微文案：按钮动词开头；确认弹窗禁用"确定/取消"，写实际动作（"删除实例"）。

## 8. 实现约束（挂风险登记 #4）

- CSS 特性基线：只用近两大版本 WebKitGTK 全绿的特性；`backdrop-filter` 必须有降级（毛玻璃→实色半透明）。
- DPI 验收：125%/150% 缩放不破版（Windows 主战场）；最小窗 960×600。
- 深色主题自定义滚动条。
- 图标单一库（lucide，stroke 宽度统一）；年代 chip 自绘。

## 9. 流程：怎么验证，而不是怎么想象

1. **浏览器里设计**：web 壳没有借口走 Figma 中转——直接 HTML/Vue 真组件、真字体、真数据出真稿。
2. 动手前截 3 个对标对象，各提炼 3 个可迁移模式（候选：Raycast、Linear、Modrinth App、Prism、BlockHelm 的亚克力质感）。
3. 验收仪式：1080p 与 1440p 各跑一遍眯眼测试 + 间距刻度抽查 + 状态完备清单。

### Definition of Polish（进 Phase 3 PR 检查单）

- [ ] stylelint 通过：无裸 hex、无刻度外数值
- [ ] 正文行长 ≤75 字符（中文 ≤45 字），超宽断栏
- [ ] 每屏 accent 实心元素恰好 1 个
- [ ] 所有数字 tabular-nums；路径/ID 等宽
- [ ] 全部交互元素五态齐全
- [ ] 动画 ≤200ms 且只动 transform/opacity
- [ ] 骨架屏无布局跳动（CLS=0）
- [ ] 深/浅主题对比度过 AA
- [ ] backdrop-filter 有降级路径
- [ ] 125%/150% DPI 不破版
- [ ] 空/错误/加载三态每屏都有定义

## 10. Attic 品牌基调（先定调，不过早定死）

一句话："**落灰，但都还活着。**"

暖木炭底 + 火把琥珀 accent + 羊皮纸文字 + 年代色码。复古元素（像素字、旧图标、全景图）是**证据，不是戏服**——只出现在内容区（版本卡、hero 背景），chrome（导航/按钮/表单）保持现代极简。这条线决定它是"精密仪器里的考古馆"，而不是"复古模板站"。
