# Attic Minecraft Launcher v0.0.8 — 启动进度弹窗 + 主题升级（强调色板 / 启动页背景图）（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.7 的增量试装版，核心是两件事：**启动时改用 HMCL 风格的进度弹窗**（含资产检查阶段全程可见），以及**主题升级**（强调色板 + 启动页背景图，设置 · 外观页）。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.7（见对应页说明）。

## 新增：启动进度弹窗（取代右上角聚合进度条）

- 点「启动」后弹出进度对话框，**全程可见**：资产校验、下载、解包、前置准备、进程拉起逐阶段列出，任务随实际执行渐进展开，不再出现「检查期间毫无显示」的静默段。
- 弹窗内「取消」即取消本次启动（含下载中断与进程终止），完成后可直接关闭；纯本地启动（无下载）同样唤起弹窗，阶段以实际执行序呈现。

## 新增：主题——强调色板

- 设置 · 外观页新增**强调色板**：火把琥珀（缺省）+ 翡翠绿 / 晴空蓝 / 熔岩橙 / 幻翼紫 / 红石红 / 石灰灰 共 7 色（色板取自 Modrinth 主题方案），点选即时生效并持久化，深浅主题各自适配色档。
- 界面按钮、焦点环、高亮随色板整体换色；背景与文字基调（暖木炭 / 羊皮纸）保持不变。

## 新增：主题——启动页背景图

- 设置 · 外观页可**选择本地图片**（png/jpg/webp/gif/bmp，≤12MB）作为主页背景，自动叠加暗色遮罩保证文字可读；「移除背景图」一键回落纯色主题背景。
- 仅配置时启用：不配置时主页保持原有纯色背景，浮层文字颜色随主题正常呈现。

## 缺陷修复：depends 暂存 zip 残留

- 启动准备阶段下载的 `libs.zip` / `natives.zip` 此前解包后残留在 launcher 目录。现解包完成即删除（对齐 Betacraft v1 语义），历史遗留文件下次启动自动清扫。

## 兼容面

- 设置档案新增两个可选键：`accentColor` / `backgroundImage`；老设置无此键一切如常，缺省 = 火把琥珀 + 纯色背景。
- 契约新增 `attic:image:data-url` 通道与 `dialog:pick` 的 `image-file` 目标（双壳镜像同步），向后兼容，老客户端不受影响。

## 已知边界

- 背景图路径为绝对路径引用：移动或删除原图后，启动器回落纯色背景（重新选择即可）。
- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——请附「控制台」页日志或 `launcher/logs/output-client.log` 与版本号。
