# Attic Minecraft Launcher v0.0.6 — 用户协议落地 + 头像断网兜底换装（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.5 的增量试装版：法律面补上正式用户协议，账户头像的断网兜底换成与官方一致的选择算法，语言词典形态解放。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.5（见对应页说明）。

## 新增：用户协议 v1.0

- 仓库根新增 `USER_AGREEMENT.md`（协议版本 1.0，2026-10-30 生效）：项目性质与 GPL-3.0 关系（协议不限制许可证授予的权利）、数据供给与版权边界、离线账户使用条件、本地数据与网络行为（**无遥测、无开发者后台、日志只在您主动提交时送达**）、运行环境与操作风险、按现状提供与责任限制、协议变更方式。
- 设置 · 关于页的「用户协议」行由占位转为可用，点击直达协议文本；README 许可证节同步入口。

## 改进：账户头像断网兜底 = 官方同款算法

- 断网（或头像服务不可达）时，不再显示手绘 Steve 一张，而是按 **Minecraft 官方 1.19.3+ 的默认皮肤规则**从您的账户 UUID 选出专属脸：9 枚默认皮肤（alex / ari / efe / kai / makena / noor / steve / sunny / zuri）× 细臂/粗臂两形态，共 18 种可能——同一个账户永远落在同一张脸上，与游戏内及主流启动器的默认皮肤行为一致。
- 18 张脸图内置于安装包（官方默认皮肤的脸部裁切，共约 4KB），完全离线可用；在线头像（minotar）路径不变，仅作加载顺序上的优先。

## 改进：语言词典从 TS 解放为 JSON

- 界面词典改为 `locales/en.json` / `zh-CN.json` 纯 JSON 形态，为未来「外挂语言包」通道（运行期覆盖层）打好同形同校验的基座；社区翻译 PR 现在只需碰 JSON 文件，无需理解 TypeScript。
- 关于页「引用的项目」按当前运行壳只显示壳自身依赖（Electron 壳列 Electron、Tauri 壳列 Tauri），并补上 Tauri 与 HMCL 的署名条目。

## 缺陷修复

- **「建议与反馈」弹窗外链静默失败**：系统未设默认浏览器时，点「报告 Issue / 功能建议」原先毫无反应；现与关于页同走统一外链通道，失败弹出明确的报错对话框（含原因与手动访问指引）。

## 兼容面

- 实例档案、数据目录布局、版本清单语义与 v0.0.5 基线一致，零破坏性变更；新增文件仅 `USER_AGREEMENT.md`（仓库文档）与安装包内置的脸图资源。
