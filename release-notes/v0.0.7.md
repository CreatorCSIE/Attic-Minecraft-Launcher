# Attic Minecraft Launcher v0.0.7 — 多人直连 MVP + 两处启动面修复（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.6 的增量试装版，核心是**多人直连**：Classic 时代服务器的 `--server/--port` 直连通道从设置、启动到命令行全链打通。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.6（见对应页说明）。

## 新增：多人直连（Classic 联机 MVP）

- **实例设置 · 新「多人直连」卡片**（基本设置之下、Addons 之上，独立保存钮）：服务器地址与端口双框填写（端口留空 = 缺省 25565），保存在实例档案上，长期生效；格式不合法会在保存前拦截提示。
- **启动页「直连 / 单人」询问弹窗**，两种形态：
  - 实例配置了服务器地址 → 启动时弹出确认，选「直连」本次启动自动进入该服务器，选「单人」照常进主菜单；
  - 实例未配置、但所选版本支持联机加入（Classic 多人版本）→ 启动时弹窗内**现场填写**地址端口再直连，一次性生效、不写档案。
- 直连为一次性注入：本次启动命令行携带服务器参数，档案与下次启动不受影响。本地回环服务器实测验收（游戏真实发起连接）。

## 缺陷修复：关窗看门狗误杀「关卡保存服务器」询问窗

- legacyfix 启动时的询问窗（是否把关卡保存到服务器）此前挂起约 10 秒会被启动器当作「游戏窗口已关闭」而终止进程。根因在启动器的关窗看门狗只认「有没有窗口」，误把询问弹窗计成游戏主窗。现改为按窗口类识别游戏主窗并加双向去抖：询问窗挂多久都不再被误杀，游戏主窗关闭仍能被正常感知。

## 缺陷修复：版本列表年代分组 1.0.0 边界串组

- 1.0 前后的候选版/更名版（rc 命名、renew 系列）在启动页年代分层中归错组。现以 release 锚 + rc 命名规则 + 更名继承三条数据规则修正，边界区版本各归其组。

## 兼容面

- 实例档案新增可选 `server` 键：老档案无此键一切如常；清空该键即恢复「不直连」。
- 启动请求新增可选 `server` 字段（一次性，与既有 `visualizer` 同款语义），双壳 sidecar 契约向后兼容，Rust 面零改动。

## 已知边界

- 直连的服务器侧密码（mppass）与正版会话校验属后置面：本地/不验服服务器不受影响，验服服务器需服务器侧关闭在线验证。
- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——请附「控制台」页日志或 `launcher/logs/output-client.log` 与版本号。
