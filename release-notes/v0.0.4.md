# Attic Minecraft Launcher v0.0.4 — 窗口坍缩真因修复（库池污染闸门）+ legacyfix 钉版直链（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.3 的增量试装版：一记根因级修复 + 一记下载通道加固。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2/v0.0.3（见对应页说明）。

## 缺陷修复

- **Indev/早期版本窗口坍缩根因修复（bin 库池污染闸门）**：`in-20100223` 等版本启动后窗口坍缩为 136x39（客户区 120x0）的问题，本版查明真因并根治——
  - **根因三段**：① 启动过 1.1–1.5.2 任一版本后，Mojang 库回填通道会把**原生** `lwjgl-2.9.0.jar`/`lwjgl_util-2.9.0.jar` 等下载进跨版本共享的 `bin/` 库池；② 库池按字母序上 classpath，`lwjgl-2.9.0.jar` 恒排在 BC 魔改 `lwjgl.jar` 之前（`-` < `.`），原生 `WindowsDisplay` 劫持类加载；③ 原生 LWJGL 2.9.0 在 Win11 的窗口序列缺陷 → 坍缩。污染一旦发生**每次启动必现**，且与"最近玩过哪个版本"看似无关，极难归因。
  - **修复**：回填通道加**污染闸门**——`org.lwjgl*` / `net.java.jinput` 族一律不落池（这两族唯一供给方是 BC depends 通道的 patched 库集，含鼠标抓取等修复）；其余无冲突库（launchwrapper 等）照常回填。
  - **已污染的用户**：升级后对受影响实例做一次**强制更新**即可（沿用 Betacraft v1 语义：先清空 `bin/` 再重铺库集）；或手动删除 `.attic/bin/` 下的 `lwjgl-2.9.0.jar`、`lwjgl_util-2.9.0.jar`、`jinput-2.0.5.jar` 后重启。
- **撤回 v0.0.3 的 DeAwtPatch V2「坍缩保底」**：上版把坍缩归因于 LWJGL 本身并以补丁钳制保底——实为**误修复**（修的是库池污染这个环境产物）。对照实锤：同一未打补丁的 legacyfix，干净库池 = 870x519 正常，污染库池 = 136x39 坍缩。本版把补丁机制回退至 v0.0.2 形态（**保留 V1 = 高 DPI 窗口偏右下修复，该修复仍有效**）；0.0.3 已打 V2 补丁的本地 jar 无害保留（钉版不匹配 = 显式跳过，不重复改写、不影响启动）。

## 通道加固

- **legacyfix 下载改钉版直链**：不再查询 `api.github.com` 的 latest release（未认证 60 次/小时/IP 限流会直接导致下载失败），改按 `agentMount` 文件名派生版本直链下载（当前钉 `26.10`）。附带红利：**版本钉死在数据表**——上游突发新 release 不会再改变实际挂载的 jar 版本。
