# Attic Launcher v0.0.2 — 取消启动 + 下载自愈（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.1 的增量试装版：两项能力升级 + 下载完整性自愈。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。

## 构件与壳定位

| 构件 | 壳 | 定位 |
|---|---|---|
| `amcl-tauri-windows-x64-*-setup.exe` | Tauri（WebView2） | **主发布线**。Win10+ 推荐；支持 0.1.0 起的静默自动更新；提供 x64 与 arm64（arm64 Windows 上游戏走系统 x64 模拟） |
| `amcl-tauri-windows-x64-*-portable.zip` 等 | Tauri · 便携形态 | 解压即用，数据 `.attic` 随盘走；适合 U 盘/受管环境 |
| `amcl-electron-windows-x64-*-setup.exe` | Electron 33 | **可选形态**。自带 Chromium，Win10+；与主壳同机共存、数据同轨；更新 = 检查 + 提示 + 手动下载 |
| `amcl-electron-legacy-windows-*-setup.exe` | Electron 22 | **Win7 SP1 – 8.1 兜底壳**。x64+ia32 合一；功能对齐主线，不提供自动更新。注：本版起分发名由 `amcl-legacy-*` 更名为 `amcl-electron-legacy-*`（壳形态在包名可见；内部数据轨不变，覆盖安装兼容旧版） |
| `amcl-tauri-macos-arm64-*.dmg` | Tauri | macOS Apple Silicon；Tier-2（可用，未全面实机验证）。游戏侧需 x86_64 Java 8（Rosetta 2），启动器启动前给明确指路 |
| `amcl-tauri-linux-x64`（deb + AppImage） | Tauri | Linux x86_64；Tier-2。Linux arm64 不分发（LWJGL2 无原生库且无模拟） |

## 新功能

- **取消启动**：资产/legacyfix 补全期间启动按钮变为红色「取消」，下载链可随时中断（AbortController 贯穿全链）；取消后界面回中性态、不记错误。游戏进程已拉起后仍走原「终止」路径，取消只覆盖下载/补全阶段。Tauri / Electron 双壳同步接线
- **下载完整性自愈**：
  - 所有下载改**原子写**：先落 `<目标>.part`，校验通过才改名就位——网络中断的半截文件不再污染「文件存在 = 可复用」判据
  - legacyfix 修复件**本地锚点三级校验**（体积 → zip 截断探测 → SHA-256）：任何一级不过 = 判定残件，自动删除重下；首次下载完成后立锚，历史存量文件首验通过即立锚（TOFU）
  - 启动期自动清扫上次进程被强杀遗留的 `.part` 残片

## 缺陷修复

- 修复 0.0.1 已知痛点：下载中断致 legacyfix 半截 jar 被直接喂给 `-javaagent`，启动失败且无法自愈——本版起残件自动识别、自动重下

## 兼容面变更

- 用户可见：兜底壳构件分发名 `amcl-legacy-*` → `amcl-electron-legacy-*`（仅改名，安装标识与数据目录不变）
- 契约面：新增 `LAUNCH_CANCEL` IPC 通道（向前兼容，壳与运行时同包分发，无跨版本组合问题）
- 实例档案、数据目录布局、版本清单语义与 v0.0.1 基线一致，零破坏性变更

## 基建与分发

- 全平台矩阵 CI 构建 + Inno Setup 安装器（用户级免管理员）
- IPC 契约夹具随 `LAUNCH_CANCEL` 通道重生成，CI 漂移绊线在位
- 仓库与安装包零版权物：游戏 jar、资产、legacyfix 修复件全部首次运行期下载
