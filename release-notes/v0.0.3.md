# Attic Minecraft Launcher v0.0.3 — Applet 窗口修复收口 + 32 位兜底 Java 供给（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.2 的增量试装版：两项用户可见缺陷修复。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2（见该页说明）。

## 缺陷修复

- **Applet 容器窗口修复收口（legacyfix DeAwtPatch V2）**：早期走 Applet 容器的版本（Pre-Classic/Indev 等）两类窗口问题一并解决——
  - 高 DPI 混缩放下窗口整体偏右下：显示模式交接窗口 frame 坐标，位置不再漂移；
  - 窗口坍缩 0x0 致首帧除零崩溃（如 in-20100223 启动即 `ArithmeticException`）：显示分辨率按**实例启动尺寸做保底钳制**，布局未定时的 0 值不再进入游戏字段。
  - 补丁以常量池级改写落进本地 legacyfix 构件，带版本钉与结构门控：不适用/未验证的构件**显式跳过并保留原 jar**（窗口维持原行为），绝不静默降级。
- **32 位兜底壳 Java 自动供给**：真 32 位系统（Win7/8.1 x86 等）且无系统 Java 时，Zulu 自动拉取现在下载 **x86 构建的 JDK 8**（此前一律拉 x64 包，游戏进程起不来）；64 位系统上跑 32 位兜底壳仍优先 x64 Java，行为不变。

## 其他

- 无限地图预览器（v0.0.2 随启动页「≡」菜单上线）实机验收通过：可点条件为本地 jar 含 `IsomPreviewApplet`（inf-20100616 – b1.7.3 区间）且 legacyfix 为 26.10 线。
- Tauri 主壳可执行文件名统一为 `Attic Minecraft Launcher.exe`（与安装器显示名一致；覆盖安装即替换，数据与更新轨不受影响）。
