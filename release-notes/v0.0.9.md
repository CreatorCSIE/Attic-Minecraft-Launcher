# Attic Minecraft Launcher v0.0.9 — 微软正版登录 + 皮肤头像 + 预设主题 + 繁體中文（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.8 的增量试装版，核心是**微软正版登录全链路**——复古联机社区服（如 Not Awesome 2）的 `[Online Mode]` 验证从此可过；外加**正版账户皮肤头像**、**预设主题**与**繁體中文**。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.8（见对应页说明）。

## 新增：微软正版登录（设备码流）

- 账户页 → 添加账户 → **正版账户**：弹窗出示设备码（一键复制 + 打开浏览器授权 + 备用链接可手动粘贴），授权完成即落账，全程无需内嵌浏览器与客户端密钥。
- **正版服直连**：带服务器参数启动微软账户时，启动器在进程拉起前代为向 Mojang 预注册会话（join），服务器侧 online-mode 校验放行——本地与公网正版服双场景实测通过；离线账户行为完全不变。
- 令牌安全：访问/刷新令牌以 Windows DPAPI（用户作用域）加密落盘，界面与日志只见脱敏视图；令牌过期启动前自动刷新，失效时账户页出现「重新验证」入口。
- **临时认证通道声明**：本版微软登录经由 Betacraft 社区公开 AppID 认证通道工作；自有 AppID 已提交 Mojang 白名单审批，获批后即切换。自持 Azure 应用者可先在数据根 `launcher/settings.json` 中设置 `microsoftClientId` 键覆盖（重启生效）。

## 新增：正版账户皮肤头像

- 微软账户头像显示**真实皮肤**（官方纹理直链，登录/刷新时自动获取），三级兜底：官方皮肤 → minotar 镜像 → 内置 UUID 默认脸；旧版已登录账户启动后自动静默补取。

## 新增：预设主题

- 设置 · 外观页新增**预设主题**一键组合：默认（主题跟随系统 + 火把琥珀）与 Modrinth（暗底 + 翡翠绿）；手动改动配色方案或强调色即回到「自定义」标记，背景图不受预设影响。

## 新增：繁體中文与语言侦测

- 语言新增**繁體中文**，下拉序 English → 简体中文 → 繁體中文；首次启动按系统语言自动选定（一次性，之后以设置为准）。
- 安装器默认语言改为 English（简体中文 / 繁體中文可在下拉中选择）。

## 兼容面

- 契约新增 `attic:accounts:ms:start|cancel|refresh` 三通道与 `attic:account:ms:login` 事件（双壳镜像同步，通道总数 40），向后兼容。
- 设置档案新增可选键 `microsoftClientId`（开发者覆盖）；`accounts.json` 新增微软账户结构（DPAPI 密文，旧版本启动器无法读取本版落盘的微软账户，降级请注意）；账户视图新增 `skinUrl` 字段。

## 已知边界

- DPAPI 加密为**本机当前 Windows 用户**作用域：换机、换用户或数据根搬移后令牌不可解，重新登录即可。
- 临时认证通道依赖社区 AppID 的白名单存续（Mojang 无保留承诺），自有 AppID 获批后此依赖解除。
- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——请附「控制台」页日志或 `launcher/logs/output-client.log` 与版本号。
