## Attic Launcher v0.0.1（试装构件）

专注远古 Minecraft 版本（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。GPL-3.0；仓库与安装包零版权物——游戏 jar、资产、legacyfix 修复件全部为首次运行期下载的数据构件。

### 本版能力
- **版本清单**：Betacraft API 290 个远古版本，浏览、下载、启动直连；版本元数据每次启动重下（上游修复即得）
- **修复容器**：legacyfix 自动挂载（`-javaagent` 决策表按版本编译日期驱动，非版本号硬编码）；c0.24 家族死链脚步声/音乐预置（启动不再空等 404）
- **Java 管理**：四级探测 + 真实 `-XshowSettings` 验证 + 64 位 Java 8 优先；无可用 Java 时 Azul Zulu 6/7/8 自动供给 + 手动导入兜底
- **实例体系**：v1 兼容实例档案（`instances/*.txt`）；版本选中即落盘；自定义版本增删与指针联动
- **账号**：微软登录 + 离线账号
- **便携版**：解压即用——exe 旁 `.attic` 随盘走；首启向导、只读介质自动回落、换盘符随身指针
- **界面**：中英双语、明暗主题、无边距自绘窗

### 已知边界
- 静默自动更新通道自 **0.1.0 stable** 起开放；本版「检查更新」仅提示新版本并跳转下载页
- Linux / macOS 为 Tier-2（可用但未全面实机验证）
- 试装构件：遇到问题欢迎在仓库 Issues 反馈
