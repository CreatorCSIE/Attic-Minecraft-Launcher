# Attic Launcher v0.0.1 — 首个可分发版本（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版本面向尝鲜与回归测试用户：全功能可用，但**静默自动更新通道自 0.1.0 stable 起才开放**，本版「检查更新」为提示 + 跳转下载页。

## 构件与壳定位

| 构件 | 壳 | 定位 |
|---|---|---|
| `amcl-tauri-windows-x64-*-setup.exe` | Tauri（WebView2） | **主发布线**。Win10+ 推荐；支持 0.1.0 起的静默自动更新；提供 x64 与 arm64（arm64 Windows 上游戏走系统 x64 模拟） |
| `amcl-tauri-windows-x64-*-portable.zip` 等 | Tauri · 便携形态 | 解压即用，数据 `.attic` 随盘走；适合 U 盘/受管环境 |
| `amcl-electron-windows-x64-*-setup.exe` | Electron 33 | **可选形态**。自带 Chromium，Win10+；与主壳同机共存、数据同轨；更新 = 检查 + 提示 + 手动下载 |
| `amcl-legacy-windows-*-setup.exe` | Electron 22 | **Win7 SP1 – 8.1 兜底壳**。x64+ia32 合一；功能对齐主线，不提供自动更新。注：自 0.0.2 起该构件更名为 `amcl-electron-legacy-*`（旧名看不出壳属） |
| `amcl-tauri-macos-arm64-*.dmg` | Tauri | macOS Apple Silicon；Tier-2（可用，未全面实机验证）。游戏侧需 x86_64 Java 8（Rosetta 2），启动器启动前给明确指路 |
| `amcl-tauri-linux-x64`（deb + AppImage） | Tauri | Linux x86_64；Tier-2。Linux arm64 不分发（LWJGL2 无原生库且无模拟） |

## 功能

- **版本清单**：Betacraft API 290 个远古版本，浏览、下载、启动直连；版本元数据每次启动重下（上游修复即得）
- **修复容器**：legacyfix 自动挂载（`-javaagent` 决策表按版本编译日期驱动，非版本号硬编码）；c0.24 家族死链脚步声/音乐预置（启动不再空等 404）
- **Java 管理**：四级探测 + 真实 `-XshowSettings` 验证 + 64 位 Java 8 优先；无可用 Java 时 Azul Zulu 6/7/8 自动供给 + 手动导入兜底
- **实例体系**：v1 兼容实例档案（`instances/*.txt`）；版本选中即落盘；自定义版本增删与指针联动
- **账号**：微软登录 + 离线账号
- **便携版**：exe 旁 `.attic` 随盘走；首启向导、只读介质自动回落、换盘符随身指针
- **界面**：中英双语、明暗主题、无边距自绘窗；控制台逐行日志 + 崩溃自动分类

## 缺陷修复（发版前实机取证项）

- Zulu 供给通道：元数据 API 真实字段为 `download_url`，原实现只认 `url` 导致自动供给静默失效（WSL Linux 实机抓到）
- Zulu 供给缓存：修复双层嵌套目录形态识别，无系统 Java 的机器不再每次启动重下 111MB JDK
- POSIX 遗留资源物化：`rmSync` ENOTDIR 平台逃逸（Linux CI 独挂）修复

## 兼容面变更

无（本版本为兼容面基线：Pre-Classic → b1.7.3/1.5.2 全区间语义以此为准）。

## 基建与分发

- 全平台矩阵 CI 构建 + Inno Setup 安装器（用户级免管理员）

- 仓库与安装包零版权物：游戏 jar、资产、legacyfix 修复件全部首次运行期下载
