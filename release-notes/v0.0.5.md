# Attic Minecraft Launcher v0.0.5 — 启动器层崩溃防线 + 游戏固定落盘日志（试装轨 prerelease）

专注远古 Minecraft（Pre-Classic → b1.7.3/1.5.2 区间）的桌面启动器。本版为 v0.0.4 的增量试装版：一记整层新能力（启动器自身崩溃不再静默消失）+ 两记体验修复。**静默自动更新通道自 0.1.0 stable 起才开放**，0.0.x 用户请从 Releases 页手动下载新版安装器，覆盖安装即升级（数据 `.attic` 原样保留）。构件矩阵与壳定位同 v0.0.2–v0.0.4（见对应页说明）。

## 新增：启动器层崩溃防线

此前启动器自身（非游戏）出错只有控制台一闪或静默失败。本版建立完整防线，崩溃现场永远留得住：

- **致命崩溃 = 原生错误对话框**：启动器主进程遇到意外错误时，弹出系统级对话框——先展示错误栈，再给三个按钮【复制诊断信息】【打开日志文件夹】【去 GitHub 报告】；选「去 GitHub 报告」会先把完整诊断包写进剪贴板、再打开预填的 Issue 页面，正文直接粘贴即可。同时全量诊断包自动写入 `launcher/logs/crash-<时间>.txt`（含版本、Electron/Node/系统信息、栈、启动器日志与游戏日志尾部）。
- **渲染窗口事故 = 报告后自动恢复**：界面进程意外消失或卡死时同样弹框取证，但启动器不退出——确认后窗口自动重载继续用。
- **非致命错误 = 现场卡片**：界面层的局部错误以弹窗卡片呈现（同款栈展示 + 三按钮 + 忽略），并静默写入 `launcher/logs/launcher.log`，不打断操作。
- **下次启动「上次崩溃」横幅**：异常退出后，下次打开启动器会先看到上次崩溃的摘要横幅（看过即消，只弹一次），不再需要用户自己发现"昨天是怎么关掉的"。

## 新增：output-client.log 游戏固定落盘日志

引入 Betacraft v1 的同名机制：每次启动游戏，本次完整日志（命令行头 + 游戏逐行输出 + 退出信息，密钥脱敏）固定写到 `launcher/logs/output-client.log`——**恒为最近一次启动**，反馈问题时直接附这个文件即可，不用再翻时间戳文件。旧的按时间戳日志文件保留，两轨并行。

## 缺陷修复

- **弹窗内拖选文字会误关弹窗**（issue #1）：在输入框里按住鼠标全选、松手时鼠标移出卡片落在灰色遮罩上，旧判据把这一下当成"点击空白关闭"，弹窗直接消失（改用户名的全选闪退即此）。判据已改为「按下就落在遮罩上才算点空白」，拖选出界完全免疫；点空白关闭的原语义保留。

## 兼容面

- 实例档案、数据目录布局、版本清单语义与 v0.0.4 基线一致，零破坏性变更；`launcher/` 下新增 `launcher.log`、`crash-*.txt`、`output-client.log`、`crash-dirty.json` 均为启动器自有文件，不触碰游戏数据。

## 已知边界

- 静默自动更新自 0.1.0 stable 起开放；Linux / macOS 为 Tier-2。
- 崩溃对话框与「上次崩溃」横幅为 Electron 壳（含 Win7 兜底壳）能力；Tauri 壳对齐数据落盘面。
- 试装构件：遇到问题欢迎在仓库 Issues 反馈——启动器崩溃现在只需点【去 GitHub 报告】一步完成；游戏问题请附「控制台」页日志或 `output-client.log` 与版本号。
